EpilespyLang Basics

EpilespyLang is a vibe-coded scripting language. Files should use the .ep extension.

Syntax Cheat Sheet
# Variable assignment
x = 42
name = "World"

# Printing
print("Hello", name)

# Scoping block
{
    temp = 100
    print(temp)
}

# Operations
res = (x + 10) * 2
Built-in Functions
  • print(...): Print values
  • input("prompt"): Read user input
  • len(val): Get length of array/string
  • num(val): Cast value to number
  • str(val): Cast value to string
  • push(arr, val): Append element to array
  • pop(arr): Remove/return last element
  • type(val): Get type name
  • sleep(ms): Sleep thread in ms
Math Constants
  • pi: 3.141592653589793
  • e: 2.718281828459045
Mathematical Functions
  • sin(x) / cos(x) / tan(x): Trig functions (rad)
  • asin(x) / acos(x) / atan(x): Inverse trig
  • atan2(y, x): Arc tangent of y/x
  • sinh(x) / cosh(x) / tanh(x): Hyperbolic trig
  • sqrt(x) / cbrt(x): Square / cube root
  • pow(base, exp): Power
  • exp(x): Exponential (e^x)
  • log(x) / log10(x) / log2(x): Logarithms
  • abs(x): Absolute value
  • ceil(x) / floor(x) / round(x): Rounding
  • min(a, b) / max(a, b): Min/max values
  • deg2rad(x) / rad2deg(x): Deg/rad conversion
