EpilespyLang Basics

EpilespyLang is a vibe-coded scripting language. Files should use the .ep extension.

Syntax Cheat Sheet
# Variable assignment
x = 42
name = "World"

# Printing
print("Hello", name)

# Scoping block
{
    temp = 100
    print(temp)
}

# Operations
res = (x + 10) * 2
Built-in Functions
  • print(...): Print values
  • input("prompt"): Read user input
  • len(val): Get length of array/string
  • num(val): Cast value to number
  • str(val): Cast value to string
  • push(arr, val): Append element to array
  • pop(arr): Remove/return last element
  • type(val): Get type name
  • sleep(ms): Sleep thread in ms
  • epilepsy(): Alternates returning 1 and 0
  • fetch(uri): Read data from online or local URI
  • window(title, w, h): Standard Win32 Window
  • gameWindow3D(title, w, h): 3D Render Window
  • win.setGravity(val): Set gravity acceleration
  • win.enableGravity(bool): Toggle gravity on/off
  • win.setCameraMode(mode): Set mode ("first", "second", "third")
  • win.jump(force): Make player jump using force
  • win.isGrounded(): Returns if player is on ground
  • gameWindow2D(title, w, h): 2D Camera Window
  • sound(filePath): Create Sound Object
  • beep(freq, duration): Async Audio Beep
  • readFile(path): Read text file to string
  • writeFile(path, content): Write string to file
  • appendFile(path, content): Append string to file
  • exists(path): Check if file/directory exists
Math Constants
  • pi: 3.141592653589793
  • e: 2.718281828459045
Mathematical Functions
  • sin(x) / cos(x) / tan(x): Trig functions (rad)
  • asin(x) / acos(x) / atan(x): Inverse trig
  • atan2(y, x): Arc tangent of y/x
  • sinh(x) / cosh(x) / tanh(x): Hyperbolic trig
  • sqrt(x) / cbrt(x): Square / cube root
  • pow(base, exp): Power
  • exp(x): Exponential (e^x)
  • log(x) / log10(x) / log2(x): Logarithms
  • abs(x): Absolute value
  • ceil(x) / floor(x) / round(x): Rounding
  • min(a, b) / max(a, b): Min/max values
  • deg2rad(x) / rad2deg(x): Deg/rad conversion
Game Engine APIs (3D/2D)
  • win.addCube(x, y, z, size, color): Add 3D Cube
  • win.addGrid(x, z, size, spacing, color): Add 3D Floor Grid
  • win.setCamera(x, y, z, pitch, yaw): Set 3D Camera
  • win.moveCamera(fwd, right, up): Move 3D Camera relative
  • win.rotateCamera(dpitch, dyaw): Rotate 3D Camera
  • win.clear3D() / win.render3D(): Manage 3D Buffers
  • win.addRect2D(x, y, w, h, color): Add 2D Rectangle
  • win.addCircle2D(x, y, r, color): Add 2D Circle
  • win.setCamera2D(cx, cy, zoom): Set 2D Camera
  • win.moveCamera2D(dx, dy): Translate 2D Camera
  • win.clear2D() / win.render2D(): Manage 2D Buffers
  • snd.play(loop): Play Audio (loop: true/false)
  • snd.pause() / snd.resume(): Control Audio
  • snd.stop() / snd.close(): Terminate/Dispose Audio
  • snd.volume(vol): Set Audio Volume (0-100)
